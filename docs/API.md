# API Contracts & Message Specifications — Microsoft License Inspector

## 1. Overview
The local backend of **Microsoft License Inspector** runs as an internal loopback REST API server listening strictly on `127.0.0.1:4820`. It enforces CORS restriction to `http://localhost:5173` (Vite dev server) and production localhost origins.

## 2. API Endpoints

### 2.1 Health & Environment Check
- **Endpoint**: `GET /api/health`
- **Purpose**: Verify diagnostic backend status and host OS capabilities.
- **Response** (`200 OK`):
```json
{
  "status": "healthy",
  "version": "1.0.0",
  "platform": "win32",
  "isWindows": true,
  "nodeVersion": "v24.15.0",
  "powershellAvailable": true,
  "timestamp": "2026-10-24T11:40:00.000Z"
}
```

### 2.2 Bulk Key Parse & Validate
- **Endpoint**: `POST /api/keys/parse`
- **Purpose**: Parse raw text or CSV entries, sanitize, validate Base-24, match GVLK, and generate masked key records.
- **Request Body**:
```json
{
  "rawText": "W269N-WFGWX-YVC9B-4J6C9-T83GX\nVK7JG-NPHTM-C97JM-9MPGT-3V66T",
  "deduplicate": true,
  "defaultProduct": "auto"
}
```

### 2.4 Error Code Dictionary
- **Endpoint**: `GET /api/error-codes`
- **Response** (`200 OK`): Map of hexadecimal Microsoft activation error codes to their official descriptions, technical causes, and recommended IT remediation steps.

### 2.5 Offline Diagnostic File Import
- **Endpoint**: `POST /api/diagnostics/import`
- **Request Body**: Raw JSON payload generated by `Invoke-LicenseDiagnostic.ps1`.
- **Response** (`200 OK`): Validated diagnostic model ready for dashboard rendering.
